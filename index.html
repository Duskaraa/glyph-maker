Glyph Maker

About

Glyph Maker 1.0.0 turns your PNGs into a Bedrock font sheet, the characters to paste in game and a ready resource pack. Nothing is uploaded.

More tools: duskaraa.github.io

Not an official Minecraft product. Not approved by or associated with Mojang or Microsoft.

Help

A glyph is a picture inside the font. The game reads font/glyph_XX.png from a resource pack: 256 cells, and each cell is a character you paste into text.

The steps

  1. Page: which sheet you make and how sharp it is. E5 and 16 work.
  2. Glyphs: drop your PNGs. One image is one glyph.
  3. Use: the character of each glyph, ready to copy.
  4. Export: download the sheet or a ready pack.

Mouse, touch and keys

  • Drop PNGs anywhere. They fill empty cells from the selected one.
  • Drag a cell onto another to move it. A full target swaps.
  • Delete clears the selected cell. Drag the picture in the cell view to place it. Arrows nudge 1, Shift 4.
  • Phone: tap an empty cell to add an image.

Problems

Click a problem to jump to it. Most have a fix button. The usual ones:

  • A glyph bigger than its cell gets cut.
  • Pixels scaled unevenly.
  • Faint pixels that add space you cannot see.
  • Your glyphs on top of the game's own icons.

Good to know

  • Every cell size shows the same size in game. A bigger cell only adds detail.
  • Space at the sides is trimmed, so move a glyph up or down inside its cell.
  • E0 and E1 belong to the game. Its icons show dimmed in the grid and stay in your export until you put your own glyph on them. E2 to F8 are free, but other packs may use the same page.
  • It does not show in Ore UI screens.
  • Put the color code f before a glyph to keep its colors.
  • Your work is saved in this browser only.

How to type

No keyboard types these. Copy the character and paste it in chat, a sign, an anvil or a command block.

In json (rawtext, tellraw, titleraw, scripts, ui files) the escape works because json decodes it.

In a .lang file paste the character itself. The escape is not decoded there.
